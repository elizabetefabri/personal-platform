# Agentes de Desenvolvimento — StudyPanel Frontend

Este diretório contém os arquivos de configuração e contexto para agentes de IA utilizados no desenvolvimento do StudyPanel Frontend.

## Estrutura

```
.agents/
├── README.md              # Este arquivo
├── context.md             # Contexto do projeto para agentes
├── component-agent.md     # Agente especializado em componentes Angular
├── style-agent.md         # Agente especializado em SCSS/design system
└── review-agent.md        # Agente de revisão de código
```

## Como usar

Cada arquivo `.md` descreve as responsabilidades, contexto e instruções para um agente específico.
Ao invocar um agente, forneça o conteúdo do arquivo como contexto inicial.
