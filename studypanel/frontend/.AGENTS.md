# StudyPanel — Guia para Agentes de IA

## Visão Geral

StudyPanel é um painel de estudos e portfólio pessoal de Elizabete Fabri, construído com Angular 21 standalone. Serve como hub centralizado para rastrear progresso em estudos técnicos e exibir projetos pessoais e profissionais.

## Stack Técnica

| Angular       | 21     | Framework (standalone, zoneless)           |
| TypeScript    | ~5.9   | Linguagem                                  |
| PrimeNG       | 19+    | Componentes UI                             |
| PrimeIcons    | 7+     | Ícones via classes `pi-*`                  |

## Sidebar — Exatamente 3 Itens

| Key            | Label          | Rota            |
| -------------- | -------------- | --------------- |
| `dashboard`    | Dashboard      | `/dashboard`    |
| `estudos-labs` | Estudos e Labs | `/estudos-labs` |
| `projetos`     | Projetos       | `/projetos`     |

Sair é botão separado. Active state: `/backend`, `/cloud`, etc. → `estudos-labs`; `/rollout-service` → `projetos`.

## Rotas

```
/dashboard
/estudos-labs                   → grid 9 seções
/projetos                       → landing 2 cards
/projetos/pessoais              → projetos pessoais
/projetos/profissionais         → projetos profissionais
/backend | /cloud | /devops ... → StudyDetailTemplate (CRUD)
/rollout-service                → StudyCardGrid de topics
/:section/:topic/:id            → course-detail (tem "Voltar para trilha")
```

## BackButtonComponent

- Inline nos headers de `StudyCardGrid`, `ProjectCardGrid`, `StudyDetailTemplate`
- NÃO adicionado a `course-detail` (já tem seu próprio botão de voltar)
- Oculto em rotas root: `/dashboard`, `/estudos-labs`, `/projetos`
- `goBack()`: navega para rota pai ou chama `location.back()`

## BreadcrumbsComponent

- Global em `app.html`, acima do `<router-outlet>`
- `baseItems`: array plain definido pelo `build()` em resposta a eventos do Router
- `items`: computed signal = `baseItems + extra` do BreadcrumbService

## Padrões de Código

- Standalone components sempre (`standalone: true`, sem NgModules)
- Imports explícitos em cada componente
- CSS BEM: `.componentName__element--modifier`
- CSS custom properties: `var(--color-*)`, `var(--sidebar-width-*)` etc.
- Signals: `signal()` e `computed()` preferíveis a propriedades mutáveis
- Sem comentários — exceto quando o WHY é não-óbvio

## Testes

```bash
npm run test:jest          # testes unitários
npm run test:jest:coverage # com cobertura
npm run test:e2e           # E2E Playwright (requer servidor em :4200)
```

- Specs unitários em `src/**/*.spec.ts`
- `StudyItemService` sempre mockado nas specs de páginas com `StudyDetailTemplate`
- Signals privados: `(component as any).signal.set(value)` nos testes
