# Componentes

## Layout

| Componente   | Selector          | Descrição                              |
| ------------ | ----------------- | -------------------------------------- |
| Header       | `app-header`      | Barra superior com breadcrumbs e título|
| Footer       | `app-footer`      | Rodapé padrão                          |
| Sidebar      | `app-sidebar`     | Navegação lateral colapsável (3 itens) |

## Navegação

| Componente    | Selector            | Descrição                              |
| ------------- | ------------------- | -------------------------------------- |
| Breadcrumbs   | `app-breadcrumbs`   | Caminho hierárquico automático         |
| BackButton    | `app-back-button`   | Voltar inline nas páginas secundárias  |

## Cards / Grid

| Componente           | Selector                | Descrição                              |
| -------------------- | ----------------------- | -------------------------------------- |
| StudyCardGrid        | `app-study-card-grid`   | Grid de cards de estudo                |
| ProjectCardGrid      | `app-project-card-grid` | Grid de cards de projeto               |
| StudyDetailTemplate  | `app-study-detail`      | Template de detalhe de curso           |
