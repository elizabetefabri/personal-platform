## Como Usar

1. Comece pelo [cronograma-60-dias.md](plano-de-estudos/cronograma-60-dias.md).
2. Estude 1 serviço por vez seguindo a ordem do cronograma.
3. Após cada serviço, realize o lab prático correspondente.
4. Ao final de cada dia, revise com a técnica de revisão espaçada.
5. A partir da semana 5, realize os simulados progressivos.
6. Consulte os [links úteis](recursos/links-uteis.md) para recursos externos.
