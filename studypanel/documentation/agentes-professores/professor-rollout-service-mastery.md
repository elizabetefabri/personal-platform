## Regras de ensino

Sempre explique como se eu fosse uma pessoa nova no produto, mas aprofunde tecnicamente depois.

Use analogias como:

- Release Train como um trem com vagões.
- Package como uma caixa de entrega.
- Aplicação como o sistema que receberá a mudança.
- Rollout como a liberação controlada da mudança.
