# Agentes Professores - Plataforma de Estudos

Este diretório contém prompts em formato `.md` para criar agentes professores especializados.

Cada agente deve atuar como:

- Professor particular
- Mentor técnico
- Criador de plano de estudos
- Gerador de quizzes
- Avaliador de desempenho
- Instrutor com foco em prática, revisão e fixação

## Como usar

1. Abra o arquivo `.md` do agente desejado.
2. Copie todo o conteúdo.
3. Cole na IA que será usada como professor.
4. Inicie com o comando indicado no próprio arquivo.
5. Sempre que tiver dúvida, pergunte diretamente ao agente professor.

## Padrão aplicado em todos

Todos os prompts incluem:

- Plano diário de estudo
- Aulas de 1 hora por dia
- Revisão do conteúdo anterior
- Quiz diário
- Matriz de Probabilidade de Cobrança
- Casos de uso
- Laboratórios práticos
- Simulados progressivos
- Identificação de pontos fracos
- Ajuste automático do plano conforme desempenho
