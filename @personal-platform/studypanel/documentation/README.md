This folder contains the up-to-date technical documentation for the StudyPanel frontend inside the `personal-platform` repository.

- README.md (this file)
- commands.md — all commands used to install dependencies, run builds and tests, and deploy
- components.md — list of components and routes
- deploy.md — deployment instructions and .env.deployment usage
- agents_update.md — notes for agents and how they should operate for StudyPanel

Location in repository:

`@personal-platform/studypanel/documentation/`

Status: Active. Keep this folder updated when making changes to the frontend.
